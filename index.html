Settings

Ye maloomat sirf is phone ke browser me save hoti hai — kisi server ko nahi bheji jati.

Ye naam room ki seats aur chat me nazar aayega.
App ID na ho to voice bilkul nahi chalegi. App ID khali chhoro to app ke andar wala default App ID use hoga (agar malik ne file me dala ho).
Zyada tar test projects me token ki zaroorat nahi hoti. Agar join par "token" wali ghalti aaye to yahan woh token dalo jo tumne Agora console se banaya ho.
Agar token server chal raha ho to yahan uska URL dalo, phir har join par token khud ban jayega aur manual token dalne ki zaroorat nahi hogi. URL khali ho to upar wala manual token hi use hoga.
Save ho gaya. Ab Home se room join karo.

App ID kahan se milega?

  1. Browser me console.agora.io kholo aur free account banao.
  2. "Create Project" dabao, project ka koi bhi naam rakho.
  3. Project kholo — wahan App ID likha milega, usay copy karke upar wale khane me dalo.
  4. Save karo, phir Home se room join karke dekho.

Ek mashwara: dono phones par wahi App ID aur wahi room naam hona chahiye, warna awaz nahi milegi.
