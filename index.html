Zako Party — Voice Test

2 phones ko jorne ka test. Koi account nahi, koi server nahi — code copy karke WhatsApp se bhejna hai. Dono phones par yehi page kholo.

Status Mic band hai. Pehle neeche wala button dabao.

Step 0 — Mic On karo

Dono phones par pehle mic on karo. Jab browser ijazat mange to Allow dabana.

Awaz ka level — mic me bolo, bar hilna chahiye:

Step 1 — Phone 1: Code banao

Sirf Phone 1 wala ye kare. Code banega, usay copy karke WhatsApp se Phone 2 ko bhej do.

Step 2 — Doosre phone ka code yahan lagao

Jo code WhatsApp par aaya hai, wo yahan paste karo. Phir:

  • Phone 2 ho (Phone 1 ka code mila hai) → Jawab banao dabao, jawab copy karke Phone 1 ko wapas bhej do.
  • Phone 1 ho (Phone 2 ka jawab mila hai) → jawab paste karke Connect karo dabao.

Call ke button

Connect hone ke baad dono ek doosre ki awaz sun sakenge.

Note: beech me ye page band mat karna, warna code kaam nahi karega aur dobara code banana parega.
