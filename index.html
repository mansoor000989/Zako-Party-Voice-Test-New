Room Settings — Seats

Khuli seats: 10 / 30

Total seats 30 hain, pehli 10 seats default khuli hain. Seats More menu ke Mic Seat se bhi badli ja sakti hain (10 / 15 / 20 / 30). Qeemat: har seat 1,000 test coins — is se 10 se 20 = 10,000 aur 20 se 30 = 10,000 banta hai, aur 15 ka step 5,000 ka hai. Seat kam karne par coins wapas nahi milenge, aur jo seats band hongi un par baithe log audience me aa jayenge. Seat limit change karne par doosre phone par bhi wahi limit lag jayegi jab chat (RTM) connect ho.

Seat par tap karo — mic menu khulega: Take, Lock, Invite, Mute.

Seat

Lock sirf khali seat par lagta hai. Lock seat doosre phone par bhi lock nazar aayegi jab chat (RTM) connect ho. Invite sirf us banday ko jata hai jo room me audience me ho (seat se utha hua ho) aur jiski chat connect ho.

4Party jaisa: pehle phone ke gaane dhoondo, phir + dabake playlist me add karo. Gaana sirf is phone ke speaker par bajega; agar tumhara mic on ho to speaker ki awaz mic se room walon ko bhi jayegi. Library aur playlist sirf is dafa ke liye hain, page band hone par khatam ho jayengi.

Ek farq samajh lo: 4Party ek asli installed app hai, is liye wo media permission se phone ke gaane khud dhoond leta hai. Ye web page (Chrome me) hai — browser security ki wajah se web page phone ki media library khud scan nahi kar sakta. Is liye pehli dafa neeche wale button se gaane chunne parenge, uske baad list bilkul 4Party jaisi dikhegi: search, + se add, ✓ matlab playlist me hai.

Settings

Ye maloomat sirf is phone ke browser me save hoti hai — kisi server ko nahi bheji jati.

Ye naam room ki seats aur chat me nazar aayega.
App ID na ho to voice bilkul nahi chalegi.
Zyada tar test projects me token ki zaroorat nahi hoti. Agar join par "token" wali ghalti aaye to yahan woh token dalo jo tumne Agora console se banaya ho.
Agar token server chal raha ho to yahan uska URL dalo, phir har join par token khud ban jayega aur manual token dalne ki zaroorat nahi hogi. URL khali ho to upar wala manual token hi use hoga.
Save ho gaya. Ab Home se room join karo.

App ID kahan se milega?

  1. Browser me console.agora.io kholo aur free account banao.
  2. "Create Project" dabao, project ka koi bhi naam rakho.
  3. Project kholo — wahan App ID likha milega, usay copy karke upar wale khane me dalo.
  4. Save karo, phir Home se room join karke dekho.

Ek mashwara: dono phones par wahi App ID aur wahi room naam hona chahiye, warna awaz nahi milegi.
